# Cachette

Cachette masque et verrouille vos apps sur Mac, comme le dossier « Masquées » de l'iPhone : les apps choisies sont rangées dans un dossier chiffré, ouvert uniquement avec Touch ID ou votre mot de passe. Dossier fermé, elles n'apparaissent ni dans le dossier Applications, ni dans Spotlight, ni dans le Dock.

Ce dépôt contient uniquement les **installateurs** de Cachette.

## Télécharger

**[Télécharger Cachette pour Mac](https://github.com/ThomasHolley/cachette-releases/releases/latest/download/Cachette.dmg)** (macOS 14 Sonoma ou plus récent, Apple Silicon et Intel).

Ouvrez le DMG et glissez Cachette dans Applications. L'appli est signée et notarisée par Apple.

---

Cachette hides and locks apps on your Mac, like the iPhone's Hidden folder: chosen apps are moved into an encrypted folder that only opens with Touch ID or your password. This repository only hosts installers; download link above.
